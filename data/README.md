# data/

このフォルダには、デモで使うデータを置きます。確認日：2026-10-16（JST）。

## templates/shikoku-landscape.json（テンプレート「四国 風景写真」）

- 内容：エリア 21（徳島県 6・香川県 5・愛媛県 3・高知県 7）、期間 4（春・夏・秋・冬）、受入条件 1、マスの必要数の初期値（エリアと期間の組み合わせごとに 2）。マスは 84 件になります。
- 出典：**このデータは自作です。** 県と市町村の名称を、手で入力して作りました。外部のデータセットは使っていません。
- 境界データ（bbox）は含みません。市町村の境界データの出典とライセンスは、まだ確認していません（requirements 12.5）。確認するまでは、市町村の照合は行わず、撮影地の判定は要確認に固定します。
- 「美波町・海陽町」は、1 つのエリアとして扱います（「・」は複合表記の区切りです）。
- 県は英字のコード（tokushima・kagawa・ehime・kochi）で持ちます。表示名は src/config/strings/prefectures.ts にあります。
- 期間は、春（3〜5 月）、夏（6〜8 月）、秋（9〜11 月）、冬（12・1・2 月）です。冬は年末年始をまたいでも同一の季節とします。
- 投入の SQL は src/worker/db/templateSeed.ts が作ります。ローカルへの投入は `npm run db:seed:local` です（SPEC/data-model.md を参照してください）。
