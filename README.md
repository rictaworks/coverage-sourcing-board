# coverage-sourcing-board

特定エリア×季節の風景写真を、条件を満たす数だけ集めるカバレッジ充足型の素材調達デモです。投稿の自動判定と、充足マップを提供します。

## 状態

要件の段階です。要件は [requirements.md](requirements.md) にあります。

## 主な内容

- 投稿：画像をブラウザで判定し、条件を満たすものを確認待ちとして受け付けます。
- 充足マップ：マスごとの採用数と必要数を表示します。
- 確認：発注者が採用・差し戻しを行います。

## ご注意

- 認証はありません。データは毎日 03:00（日本時間）に消去されます。
- 投稿する写真は、ご自身が撮影したものだけにしてください。人物や個人情報が写るもの、機密の画像は投稿しないでください。
- 位置情報（GPS）と機種情報は保存しません。
