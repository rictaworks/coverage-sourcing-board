# 一次判定・重複の判定・日の出と日の入りの仕様（B3）

確認日：2026-10-16（JST）。この文書は、実装済みの純粋なクラスと関数の仕様です。実装は `src/core/validation/` にあり、DOM・Canvas・Node 固有の API を使いません。

## 1. 共通

- 判定の結果は `CheckResult`（項目・判定・理由のコード）で返します。判定は `pass`（合格）・`fail`（不合格）・`review`（要確認）です。`info`（補助）は使いません（被写体区分は B3 の判定に含めません）。
- 理由のコードは `src/core/validation/reasonCodes.ts`、理由と修正方法の文言は `src/config/strings/checks.ts` にあります。両者のキーが一致することを、テストで確かめます。
- 既定値は `src/config/defaults.ts`（RULE_DEFAULTS）を正とします。県庁所在地は `src/config/geo.ts` にあります。
- 画素数の上限（4,000 万画素）の前段の判定（D3）は呼び出し側の担当です。`Validator` は寸法の値を受け取って判定します。

## 2. Validator（一次判定）

`new Validator(daytime: DaytimeJudge).validate(input, rule)` で、投稿の全項目を判定します。

| 項目 | 判定 | 境界 |
|---|---|---|
| 形式（format） | `rule.formats`（JPEG・PNG）以外は不合格 | - |
| 向き・比率（orientation_ratio） | 縦向き（高さ > 幅）は不合格。縦向きでは比率を判定しません。比率は 4:3 の許容誤差 1%（`rule.tolerance`）。 | 誤差が 1% ちょうどは合格（境界を含む）。浮動小数の誤差は 1e-9 で吸収します。 |
| 解像度（resolution） | 入力が 5 MB（5,242,880 バイト）超、画素数が上限超、短辺が 800 px 未満は不合格。 | 5 MB ちょうど、短辺 800 px ちょうどは合格。 |
| JPEG 品質（jpeg_quality） | 50 未満は不合格、50〜59 は要確認、60 以上は合格。推定できない（PNG など）ときは判定しません（結果を返しません）。 | 49 不合格、50 と 59 要確認、60 合格。 |
| ピント（focus） | 30 未満は不合格、30 以上 60 以下は要確認、60 を超えたら合格。 | 29.9 不合格、30 と 60 要確認、60.1 合格。 |
| 撮影地（shoot_location） | 常に要確認（境界データがないため。requirements 12.5）。不合格にしません。 | - |
| 撮影月・季節（shoot_month_season） | 撮影月の申告が無い、または 1〜12 の整数でなければ不合格。EXIF の撮影月（時差を反映）と申告が違えば要確認。季節は月から導出します（`seasonOfMonth`）。 | EXIF の撮影日時が無いときは月の比較を行いません。 |
| 昼間（daytime） | EXIF の撮影日時がある場合、県庁所在地のいずれかで昼間なら合格、どこでも夜なら不合格。EXIF が無い場合は平均輝度が 40 未満なら要確認。 | 平均輝度 39.9 要確認、40 合格。 |
| 加工（processing） | 平均彩度が 0.05〜0.85、コントラストが 0.1〜0.8 の外なら要確認（仮の値。実測で調整します）。 | 範囲の両端は合格。 |
| 申告（declaration） | 「AI で生成した画像ではない」と「他のサイトで使っていない」の両方が必要。どちらかが無ければ不合格。機種情報が EXIF に無ければ要確認。 | - |

- 不合格が 1 つでもあれば投稿は保存しません（`Validator.overallOutcome` は `reject`）。それ以外（要確認のみ、または全項目合格）は確認待ちとして保存します（`pending_review`）。
- 撮影地は、境界データの出典とライセンスを確認するまで、常に要確認にします（境界データの確認後に見直します）。
- 位置情報（GPS の座標）と機種情報の値は、判定の結果に含めません。

### 既定値（requirements 3.0）

| 値 | 出所 |
|---|---|
| 比率 4:3・許容誤差 1%・横向き・5 MB・4,000 万画素・短辺 800 px | `defaultAcceptRule()`（RULE_DEFAULTS を参照） |
| JPEG 品質 50・60、ピント 30・60、平均輝度 40、同一画像 4・8 | RULE_DEFAULTS |
| 加工の彩度・コントラストの範囲 | RULE_DEFAULTS（仮の値） |

## 3. DuplicateChecker（重複の判定）

`new DuplicateChecker(rule).check(submission, existing)` で判定します。比較の対象は同じセッションの投稿だけです（requirements 2.3）。

- **同一画像**：知覚ハッシュの距離（16 進 16 文字のハミング距離）。4 以下は不合格、5〜8 は要確認、9 以上は合格。複数の既存の投稿と比べ、最も厳しい判定を返します。要確認と不合格の結果には、比較した既存の投稿の ID（`candidateIds`）を含めます。
- **同一地点**：同じ市町村×同じ季節で、地点名を正規化（NFKC・空白の整理・複合表記の区切り）したうえで一致したら要確認。季節が違う投稿、市町村が違う投稿は対象外です。地点名が空欄（空白だけを含む）の投稿は、この判定を行いません（結果を返しません）。
- 不正な形式のハッシュは例外にします。

## 4. SunCalculator（日の出と日の入り）

`SunCalculator` は `DaytimeJudge` を実装します。`isDaytime(date, lat, lng)` は、日の出から日の入りの間なら `true` を返します。

### 4.1 計算の方法

- NOAA の太陽位置の式（平均近点角・均時差・赤緯）で、太陽の南中を求め、時角から日の出と日の入りを求めます。
- 太陽の上辺が地平線に一致する天頂距離 90.833 度（大気の屈折を含む）を使います。
- 南中は、赤緯と均時差を南中の時刻で 2 回反復して求めます。
- 極地では、日の出と日の入りがないことがあります（白夜・極夜）。このときは `polar` を `day` または `night` で返します。
- 誤差の目安は分単位（1 分程度）です。夏時刻は考慮しません（日本では実施していません）。

### 4.2 日時の扱い

- EXIF の撮影日時は `toShotInstant(wallClock, offsetMinutes)` で瞬間に変換します。時差（OffsetTimeOriginal）があればそれを使い、無ければ日本時間（+540 分。`JST_OFFSET_MINUTES`）とみなします。
- `isDaytime` は、前日・当日・翌日の南中のそれぞれで判定し、いずれかの区間に入っていれば昼間とします。

### 4.3 県庁所在地と判定の方法

- 使う地点は徳島市・高松市・松山市・高知市の 4 件です（`src/config/geo.ts`）。
- 市町村の境界データがないため、どの市町村で撮影したかは分かりません。そこで「4 件のいずれかで昼間なら昼間」としました。四国内の日の出の時刻の差は数分程度なので、この判定は昼間の投稿を誤って不合格にしにくくします。
- 座標は市役所の概略の値です。国立天文台の暦計算室の表示値（0.05 度単位）と整合することを確認しています（確認日 2026-10-16）。出典の一次資料（市役所の公式の座標）は、人が確かめてください。

### 4.4 参照値と誤差

参照値は、国立天文台 暦計算室「高松(香川県)の日の出入り」（令和 8 年 2026 年の月別表。JST の分単位）です。

| 日付 | 日の出（参照・計算） | 日の入り（参照・計算） | 誤差（分） |
|---|---|---|---|
| 2026-06-01 | 04:53・04:52 | 19:11・19:10 | 0.2・0.6 |
| 2026-06-21 | 04:52・04:52 | 19:19・19:19 | 0.0・0.1 |
| 2026-12-01 | 06:51・06:51 | 16:54・16:53 | 0.6・0.2 |
| 2026-12-21 | 07:06・07:06 | 16:58・16:57 | 0.0・0.6 |
| 2026-01-01 | 07:10・07:10 | 17:05・17:04 | 0.1・0.7 |

- 参照値の URL：`https://eco.mtk.nao.ac.jp/koyomi/dni/2026/s3806.html`（06 月）、`s3812.html`（12 月）、`s3801.html`（01 月）。
- テストの許容は ±10 分です（Issue の受け入れ条件）。
- 国立天文台の表示は 1 分単位で切り捨てた値のため、差の目安に±1 分の表示の誤差があります。
